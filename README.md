# EcoColeta Mary Dota

> Projeto elaborado para a **Atividade Extensionista II** do curso de **Análise e Desenvolvimento de Sistemas** da **UNINTER**.

## Sobre o projeto

O EcoColeta Mary Dota é uma solução digital (site) criada para facilitar e estimular o descarte correto de lixo eletrônico pelos moradores do Núcleo Habitacional Mary Dota e região, em Bauru/SP, em articulação com o Ecoponto Mary Dota.

O site permite que os moradores:

- conheçam a importância do descarte correto de e-lixo e seus impactos ambientais e sociais;
- agendem a coleta de resíduos eletrônicos por meio de um formulário simples ou pelo WhatsApp;
- acessem informações claras sobre privacidade e uso dos dados coletados (LGPD).

O objetivo do projeto é aproximar a comunidade dos serviços de descarte correto de resíduos eletrônicos, fortalecendo o vínculo entre a população local e os serviços públicos, alinhado aos Objetivos de Desenvolvimento Sustentável (ODS) da ONU.

## Tecnologias

- HTML5, CSS3 e JavaScript puro
- Navegação SPA (Single Page Application) via roteamento por hash
- Integrações externas: [ViaCEP](https://viacep.com.br/) (busca de endereço) e [EmailJS](https://www.emailjs.com/) (envio de e-mail do formulário)

## Como executar localmente

1. Clone ou baixe este repositório.
2. Sirva os arquivos por um servidor local (por exemplo, a extensão "Live Server" do VS Code), em vez de abrir o `index.html` diretamente pelo navegador.
3. Acesse o endereço local indicado pelo servidor.
